# Fotball-IQ / Football IQ

Endless football decision puzzles that train how you read the game. Available in **Norwegian** and **English**.

## How it works

Pick a role (Keeper, Defender, Midfield, Winger, Striker, or Mixed) and solve situations on a tactics board:

- **Passing** – you have the ball. Who should you pass to?
- **Pass or shoot** – near the box: pass to a teammate or shoot?
- **Distribution** – as the keeper, find the free player to start the attack.
- **Movement** – a teammate has the ball. Which spot should you run to?
- **Defending** – the opponent attacks. Who should you mark?

Every puzzle is generated on the fly, so there is no end to them. Each answer is checked against real tactical
principles: passing lanes, pressure on the receiver, offside, progression up the pitch, scoring chance
(angle and distance to goal), spacing between teammates, and the danger an attacker poses. After each answer you
get an explanation of your choice, the best choice, and a coaching tip. Difficulty goes up as you solve more
(more opponents, closer options, no offside line shown).

Progress (score, streak, accuracy per role, language) is saved in the browser.

## Run it

It's a single file with no build step. Open `index.html` in a browser, or host the repo with GitHub Pages
(Settings → Pages → deploy from branch).
